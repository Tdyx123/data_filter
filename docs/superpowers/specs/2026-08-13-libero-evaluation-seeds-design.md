# LIBERO 固定评测种子更新设计

## 目标

将 Octo-small LIBERO 评测的三个固定随机种子从 `0`、`1`、`2` 更新为
`3471197683`、`1232873419`、`1448008435`，并保持复用同一协议常量的 Qwen
LIBERO 评测器与其一致。

## 设计

- 将 `src/octo_small_libero/evaluation.py` 中共享的 `EVALUATION_SEEDS` 更新为
  `(3471197683, 1232873419, 1448008435)`。
- 不增加新的命令行参数；三个种子仍是固定评测协议的一部分，episode 数量与
  “必须能被三个种子整除”的验证规则不变。
- 同步 Octo 命令行帮助、`evaluate_libero_octo_small.sh` 帮助和 README 中展示的
  默认种子，避免运行行为与说明不一致。
- 更新 Octo 与 Qwen 的相关回归测试期望，因为 Qwen 评测器有意复用同一个
  `EVALUATION_SEEDS` 常量。

## 验证

先修改测试期望并运行相关测试，确认它们因实现仍使用旧种子而失败；随后更新实现
与文档，再运行 Octo 评测、Qwen 评测和 shell launcher 的相关测试。最后执行 shell
语法检查，并搜索旧种子描述，确认本次协议涉及的位置均已同步。

## 非目标

- 不允许用户在命令行覆盖固定种子。
- 不改变 episode 数量、初始状态顺序、并行度或其他评测参数。
- 不执行真实 GPU/MuJoCo 闭环评测；本次仅运行不依赖硬件的回归测试。
