# LIBERO 平均成功率汇总脚本设计

## 目标

新增一个只读 Python 脚本，扫描 `/data/dwb/octo_small_libero/` 的直属子文件夹，
仅输出已完整完成 LIBERO-10 十个任务的实验及其任务平均成功率。任何存在失败、
未完成、缺失或无效任务结果的实验文件夹都不会进入输出。

## 命令行接口与输出

脚本路径为 `scripts/summarize_libero_success_rates.py`。位置参数 `ROOT` 可选，默认值为
`/data/dwb/octo_small_libero/`，以便对实际结果目录直接运行，也便于使用临时目录测试。

脚本只扫描 `ROOT` 的直属子文件夹，按平均成功率从高到低输出；平均成功率相同时按
文件夹名称升序输出，保证结果稳定。每行只包含实验文件夹名和格式化为百分比的平均
成功率，例如：

```text
relcore_top20pct  31.27%
```

不会输出逐任务成功率、按 seed 成功率、成功次数或失败次数。被跳过文件夹的诊断信息
写入标准错误，避免污染标准输出；根目录不存在、不是目录或无法读取时返回非零状态。

## 文件夹有效性判定

每个实验文件夹必须包含 `task-0` 至 `task-9` 十个子目录，且每个子目录必须存在可解析
的 `results.json`。脚本完全忽略 `failure.json`，即使它与已完成的 `results.json` 同时
存在也不影响判定。

每个 `results.json` 必须同时满足：

- 顶层 `status` 严格等于 `"complete"`；
- `protocol.episodes` 是正整数；
- `summary.completed_episodes` 是非负整数，并且严格等于 `protocol.episodes`；
- `summary.success_rate` 是有限数值，且位于闭区间 `[0, 1]`。

缺少任意任务目录或结果文件、JSON 无法解析、字段缺失、字段类型错误，或任一上述条件
不成立时，跳过整个实验文件夹。Python 的布尔值不作为整数或成功率接受。

## 汇总计算

有效实验的平均成功率是十个 `summary.success_rate` 的等权算术平均值：

```text
mean = sum(task_success_rates) / 10
```

不根据 episode 数加权，不从 `episodes.jsonl` 重新计算，也不使用
`summary.by_seed`。这是“只使用平均成功率”的唯一汇总口径。

## 结构与错误处理

脚本只使用 Python 标准库。核心逻辑分为结果文件解析、单实验校验和根目录汇总三个
小函数，命令行入口只负责参数解析、排序输出和错误状态。预期的数据问题导致相应实验
被跳过并产生一条简洁诊断；只有根目录级错误导致整个命令失败。

脚本不写入或修改评估结果目录，不引入配置文件，也不改变现有评估流程。

## 测试

新增 `tests/test_summarize_libero_success_rates.py`，使用临时目录覆盖：

- 两个完整实验按十个任务的算术平均成功率降序输出；
- 平均值相同时按文件夹名稳定排序；
- `failure.json` 存在时仍只依据有效的 `results.json` 输出；
- 缺少任意 `task-0` 至 `task-9` 或 `results.json` 时跳过整个实验；
- 状态不是 `complete` 或完成回合数不足时跳过整个实验；
- JSON 损坏、必需字段缺失、类型错误、非有限成功率或越界成功率时跳过整个实验；
- 根目录不存在或不是目录时返回非零状态；
- 没有有效实验时标准输出为空。

实现遵循 TDD：先添加因脚本尚不存在而正确失败的测试，再编写最小实现，并运行目标
测试及相关回归测试。
